# 📱 حاسبة الفليكسي - موبيليس (Mobilis Flexy Tracker)

تطبيق متكامل لتتبع وتسجيل رسائل تعبئة الرصيد (الفليكسي) القادمة من شبكة **موبيليس (Mobilis)** تلقائياً وبذكاء، مع احتساب الصافي والخصم المئوي (افتراضياً 10%) بالدينار الجزائري (DZD) والسنتيم.

---

## ✨ المميزات الرئيسية

- 🟢 **كشف ذكي وتلقائي لرسائل موبيليس (Mobilis)**:
  التعرف الفوري على الرسائل الواردة من `644, 600, 606, Arseli, Mobilis, MOBILIS` وصيغ الرسائل المختلفة مثل:
  > *"Vous avez rechargé 100.00 DZD DA avec succès le 13/08/2026 15:52:46. Profitez d’une multitude d’avantages avec les nouvelles offres MOBILIS."*

- ⚡ **إيقاف توفير البطارية للتطبيق**:
  خيار مباشر داخل الإعدادات للسماح للتطبيق بالعمل المستمر في الخلفية دون أن يوقفه نظام أندرويد.

- 💰 **احتساب الصافي والخصم فورياً**:
  تحديد نسبة الاقتطاع (10% أو حسب الرغبة) وحساب الصافي الإجمالي واليومي/الشهري تلقائياً.

- 🇩🇿 **دعم العرض بالدينار والسنتيم الجزائري**:
  إمكانية التبديل بين الدينار الجزائري (DA) والسنتيم (ملايين/آلاف) بنقرة واحدة.

- 👨‍💻 **صانع ومطور البرنامج**:
  `ALILI ABD ELAZIZ AZA` — الإصدار `v2.2.1`
